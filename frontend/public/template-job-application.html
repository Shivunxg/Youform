Frequently asked questions

Can applicants upload their CV or resume?

Yes. FormflowX supports file upload questions for any file type — PDF, DOC, DOCX, images. You set the accepted types and maximum file size per upload field.

Can I show different questions for different roles?

Yes. Use conditional logic: when an applicant selects "Engineering", show engineering screening questions; when they select "Sales", show sales questions. Applicants only ever see what's relevant to their role.

How do I track applicants without an ATS?

The simplest approach is connecting to Notion — every submission creates a database entry. Add a "Status" select property (Applied, Reviewing, Interview, Offer, Hired, Rejected) and you have a functional applicant tracker in minutes. Google Sheets works well for smaller teams.

Is this template free?

Yes. The job application template is free to use, customise, and publish on the FormflowX free plan (up to 100 responses/month). File uploads are included on all plans.
