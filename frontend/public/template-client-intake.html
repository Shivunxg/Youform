FAQ

Common questions

What is a client intake form?

A client intake form collects structured information from a new client before you start working together — their project goals, budget, timeline, communication preferences, and any existing assets. It replaces or shortens the discovery call and ensures you have everything you need to scope the work accurately.

Can clients upload files in this form?

Yes. FormflowX supports file uploads on all plans. Clients can attach brand guidelines, existing designs, reference images, or any other documents. Free plan supports up to 10MB per file; Pro supports up to 50MB.

Can I add my own questions?

Completely. All questions in the template are fully editable — change the text, add new questions, remove ones that don't fit your service, and reorder them. You can also add conditional logic to show different questions based on earlier answers (e.g. only ask for a brand brief if they selected "Yes, I have existing assets").

Can I use this as a freelancer or agency?

Yes — this template is designed for both. Freelancers can use the free plan to collect up to 100 client intakes per month. Agencies with multiple clients and a high volume of submissions will benefit from Pro or Business, which remove branding and support higher response limits.
